# Virtual Store: Customer Order Management
A software solution designed to streamline the process of placing and tracking customer orders.

## Project Scope
This project focuses on the **Analysis and Development** of a virtual storefront where:
* Customers can browse products.
* Users can place and manage orders.
* Admins can view order history and statuses.

# Technical Goals
* Implement **UML Modeling** for the ordering process.
* Follow **IEEE 830** standards for software requirements.
* Utilize **Git** for version control.
